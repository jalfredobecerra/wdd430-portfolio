# wdd430-portfolio

A personal portfolio site built with Next.js, TypeScript, and Tailwind CSS, showcasing my projects and background.

## Live Demo

🔗 [https://wdd430-portfolio-five-tan.vercel.app/](https://wdd430-portfolio-five-tan.vercel.app/)

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Features

- Home page with a portfolio project list
- About page with background info and a skills overview
- Reusable components: Header, Footer, ProjectCard, ProjectList, SkillCard
- Simple API route (`/api/hello`)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
